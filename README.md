# Fluorescence Signal Analysis Pipeline

<img width="996" height="817" alt="image" src="https://github.com/user-attachments/assets/a582d263-aeca-41c4-8df0-b571a149b722" />


A MATLAB pipeline for extracting ROI-based fluorescence signals from TIFF image stacks and detecting fluorescence events.

The pipeline consists of two main steps:

```text
Fluorescence images
        │
        ▼
   image2signal
        │
        ▼
ROI fluorescence signals
        │
        ▼
     plotSpike
        │
        ▼
Fluorescence event analysis
```

## Overview

### 1. `image2signal`

Extracts fluorescence signals from ROIs defined in Fiji/ImageJ.

For each ROI, the script calculates the mean fluorescence intensity across all frames of the selected TIFF image stack.

### 2. `plotSpike`

Processes the extracted fluorescence signals and provides a graphical interface for:

- background correction and smoothing;
- fluorescence peak detection;
- detection of the rise preceding each peak;
- visualization of individual ROI/cell traces;
- adjustment of detection parameters;
- manual addition or deletion of detected events; and
- saving the analyzed data.

---

# Requirements

## MATLAB

The pipeline requires MATLAB and the following functions:

```text
ReadImageJROI
load_tiffs_fast
FBackCorr
derivate
distinguishable_colors
```

MATLAB functions used by the scripts, such as `findpeaks`, `poly2mask`, and `smooth`, may also require the corresponding MATLAB toolboxes.

## Fiji/ImageJ

ROIs should be drawn in Fiji/ImageJ and saved as an **ROI Set (`.zip`)**.

---

# Workflow

## Step 1 — Prepare ROIs in Fiji/ImageJ

1. Open the fluorescence image in Fiji/ImageJ.
2. Draw the ROIs that you want to analyze.
3. Add the ROIs to the ROI Manager.
4. Save the ROIs as an ROI Set (`.zip`).

The same ROI Set should be used for extracting fluorescence signals and, when necessary, grouping ROIs during subsequent analysis.

---

## Step 2 — Prepare the image files

The input images should be motion-corrected TIFF stacks with filenames in the following format:

```text
MMM_DDD_NNN_MotCor.tif
```

where `NNN` is the ID of the recording.

For example:

```text
011_008_019_OUT_MotCor.tif
```

---

## Step 3 — Run `image2signal`

Run:

```matlab
image2signal
```

The script will ask you to:

1. Select the Fiji/ImageJ ROI Set (`.zip`).
2. Select one or more `*_MotCor.tif` image files.

The script calculates the mean fluorescence intensity within each ROI for every imaging frame.

For each TIFF file, a MATLAB file containing the variable `activs` is generated.

`activs` is organized as:

```text
rows    = imaging frames
columns = ROIs
```

The output filename is based on the corresponding image filename, for example:

```text
011_008_019_OUT_MotCorROI analysis.mat
```

The ROI analysis files can be stored in a different folder from the MATLAB scripts. `plotSpike` loads the files from the location selected by the user.

---

# Step 4 — Define the `plotSpike` inputs

`plotSpike` requires three inputs:

```matlab
plotSpike(ROIgroup, ROIlabel, time)
```

## `ROIgroup`

Defines which ROIs are treated as individual fluorescence traces.

To analyze every ROI independently:

```matlab
ROIgroup = num2cell(1:58);
```

This produces:

```matlab
ROIgroup = {1, 2, 3, ..., 58};
```

To combine multiple ROIs into individual traces:

```matlab
ROIgroup = {1:5, 6:10};
```

In this example, ROIs 1–5 are combined into one trace and ROIs 6–10 into another.

When multiple ROIs are grouped, `plotSpike` uses ROI-size-weighted averaging to calculate the combined signal.

## `ROIlabel`

Defines the label displayed for each trace.

For example:

```matlab
ROIlabel = cellfun(@(x) ['Cell ' num2str(x)], ...
    num2cell(1:length(ROIgroup)), ...
    'UniformOutput', false);
```

Alternatively, labels can be specified manually:

```matlab
ROIlabel = {'Cell 1', 'Cell 2'};
```

## `time`

Contains the timestamp of every imaging frame, in seconds.

For example, for 310 frames acquired over 10 seconds:

```matlab
time = 0:10/310:10-10/310;
```

The number of timestamps must be equal to or greater than the number of frames in the fluorescence recording.

---

# Step 5 — Run `plotSpike`

After defining the inputs, run:

```matlab
plotSpike(ROIgroup, ROIlabel, time);
```

When prompted, select:

```text
Create New Project
```

Then:

1. Select one or more ROI analysis `.mat` files generated by `image2signal`.
2. If multiple files are selected, you can optionally save the selected files as a `*list.mat` file for easier loading in the future.
3. Select the corresponding Fiji/ImageJ ROI Set (`.zip`).

`plotSpike` will then automatically perform:

```text
ROI fluorescence signals
```
